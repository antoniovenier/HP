O quê: `TIMESTAMP_RECENTE_MAX_MIN = 5`. Por quê: o carimbo real é `3m`; "de agora" passa a ser "até 5 min" num lugar só
(o `story_fluxos` lê daqui). Testes: `test_fixture_real_3m_vira_3_minutos_no_story_post_e_no_story_fluxos`.

```python

TIMESTAMP_RECENTE_MAX_MIN = 5
```

### Patch 3 — `scripts/story_post.py`, função nova `_de_agora()` (após `minutos_do_timestamp`) e `avancar_ate_story_de_agora`

O quê: o teste "é de agora" passa a olhar texto **e** content-desc do cabeçalho (`reel_viewer_text_container`) pela regra do
`story_fluxos`; sem o módulo (PC só com a rodada 1), cai no `minutos_do_timestamp` de sempre. Por quê: o dump real tem o
carimbo em dois lugares e o content-desc é o mais explícito ("3 minutes ago"). Testes: `test_fixture_real_3m…`,
`test_fluxo_completo_sequencia_de_comandos` (rodada 1, 2 avanços continuam).

Antes:
```python
        sumiu = 0
        m = minutos_do_timestamp(ts.texto)
        if m is not None and m <= lim:
            return ts
```
Depois:
```python
        sumiu = 0
        cab = ctx.tela.achar(nos=nos, id=["reel_viewer_text_container"])
        if _de_agora(ts.texto, cab.desc if cab else "", lim):
            return ts
```
e a função nova:
```python
def _de_agora(texto, desc: str, limite_min: float) -> bool:
    try:
        from story_fluxos import eh_timestamp_de_agora
    except ImportError:
        m = minutos_do_timestamp(texto)
        return m is not None and m <= float(limite_min)
    return eh_timestamp_de_agora(texto, desc or "", limite_min)
```

### Modo de acento real (DESLIGADO; o padrão `sem_acento` já funciona) — passo a passo

O `adb shell input text` não digita acento nem emoji. O padrão troca ("Você" → "Voce") e avisa no log. Se quiser acento de
verdade, é uma decisão sua (instalar APK) e são estes os passos — o script não faz nenhum deles:
